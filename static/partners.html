For providers and partners

Partners

For API providers and integration partners — badge, embeddable snippet, logo, and press kit. Live figures are never hardcoded on this page: check apibase.pro/llms.txt for the current tool/provider count.

APIbase is a single MCP + REST endpoint that lets AI agents discover, evaluate, pay for, and call tools from many API providers — without a separate signup, API key, or integration per provider. Payment is per call in USDC, settled through either the x402 rail on Base mainnet or the MPP rail on Tempo, with no subscription and no dashboard step between finding a tool and calling it. Full mechanics: /why.

For API providers

Listing a provider's API on APIbase puts it in front of agents that already discover, price-check, and pay for tools through the same endpoint — instead of requiring every agent developer to integrate that API directly. Providers keep their own API; APIbase wraps it as one or more priced tools behind the shared MCP + REST surface, handles discovery, schema validation, and the payment/escrow flow, and forwards calls straight through.

Brand usage: keep the logo's aspect ratio and clear space; do not recolor it or place it on a background that breaks contrast; do not imply an endorsement or partnership beyond "available via APIbase MCP" without separate written agreement.

Live facts, not static ones: for anything that changes over time — tool count, provider count, category list — link to apibase.pro/llms.txt or apibase.pro/why instead of quoting a number, since anything printed here or in a partner's own docs stops being checked the day it's published.
