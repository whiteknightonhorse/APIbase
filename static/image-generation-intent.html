Use case

Image generation API with pay-per-call access for AI agents

Stable Diffusion, behind the same endpoint as every other tool — no separate Stability AI account, no monthly plan.

Live tool

ToolPriceWhat it does
stability.generate$0.07Generate images from text prompts via Stable Diffusion — style presets (anime, cinematic, pixel-art, photographic, and others), configurable aspect ratio, negative prompts. Returns a base64 PNG data URI directly in the response.

Current price and full input schema (prompt, negative_prompt, aspect_ratio, style_preset): /api/v1/tools (filter with ?category=media) or GET /api/v1/discover?intent=generate+image.

How to call it

curl -X POST https://apibase.pro/api/v1/tools/stability.generate/call \
  -H "Authorization: Bearer ak_live_..." \
  -H "Content-Type: application/json" \
  -d '{"params": {"prompt": "a lighthouse at sunset, cinematic", "aspect_ratio": "16:9"}}'

Response is delivered as a data URI — no separate download step, no expiring signed URL to fetch before it lapses. Not authenticated yet? /connect covers getting a key, or paying directly from a wallet with no key at all.

What this doesn't claim

One model family, one price point. If a task needs a different model or a bulk-generation workflow, that's a gap today, not something silently substituted — the tool call itself is the full extent of what's offered here.
