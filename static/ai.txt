## What We Do
APIbase aggregates 1387 tools from 401 providers into a single MCP endpoint.
Any AI agent can discover, call, and pay for tools through one entry point.

## For AI Agents — Quick Start
1. Connect: POST https://apibase.pro/mcp (Streamable HTTP, MCP protocol)
2. Discover: Call the apibase.discover tool (or GET /api/v1/discover) → browse 1387 tools by intent or category (the discover_tools prompt is kept for backward compatibility)
3. Call tools: tools/call with any tool name → pipeline handles auth, payment, caching
4. Full catalog: GET https://apibase.pro/api/v1/tools → all 1387 tools with JSON schemas

## Progressive Disclosure (recommended for 1387 tools)
Instead of loading all tool schemas into context, use apibase.discover (GET /api/v1/discover):
- apibase.discover (no args) → best-ranked matches across the catalog
- apibase.discover category="travel" → travel tools only (aviasales, sabre, ...)
- apibase.discover intent="find flights from NYC" → relevant tools ranked by relevance
All 1387 tools remain callable regardless of discovery — discovery is advisory only.

## Payments
Protocol: x402 (HTTP 402 Payment Required) or MPP (Authorization: Payment)
Token: USDC on Base mainnet (x402) or USDC.e on Tempo (MPP)
Prices: $0.0005–$29.99 per call (p90 $0.003); <!--free-tools-->8<!--/free-tools--> platform tools are free ($0)
Details: https://apibase.pro/.well-known/x402-payment.json
MPP client: mppx >= 0.6.16 (0.4 clients are not supported); one currency in the challenge: USDC.e on Tempo mainnet (pathUSD on the testnet)
A replayed MPP credential gets 403 credential_replayed

## Agent Integration Guide
Match price to wallet — fetch only tools you can afford:
  GET /api/v1/tools?max_price=<usd>   → tools priced at or below <usd>
  GET /api/v1/tools?tier=micro        → micro-priced tools

Each tool entry includes:
- pricing.price_usd           — sticker price per call
- pricing.cache_hit_price_usd — discounted balance-tier rate
- tier                        — price tier of the tool
- min_balance_usd             — minimum on-chain USDC required
- input_schema                — JSON Schema for the call body

The 402 payment challenge body also includes price_usd + min_balance_usd
so agents can short-circuit signing if their wallet balance is insufficient.
